# Harinee Catering Services ("Feel The Taste")

Official high-performance, High-SEO multi-page web application for **Harinee Catering Services** (Proprietor: Chef V. Manivannan, Trichy, Tamil Nadu).

---

## 🌟 Key Features

1. **Multi-Page Architecture (`react-router-dom`)**:
   - `/` - Dynamic Landing / Home Showcase with quick estimator, popular packages, and partner halls.
   - `/menus` - 5-Category interactive menu explorer (Morning Tiffin, Traditional Lunch, Evening High-Tea, Dinner Buffets, Valaikappu) with intelligent phonetic/fuzzy search.
   - `/estimator` - Interactive event cost calculator and real-time custom quotation builder with direct WhatsApp dispatch.
   - `/live-stalls` - 16 specialty live stalls showcase (Dosa, Chaat, Tandoori, Kulfi, Cotton Candy, Chocolate Fountain, etc.).
   - `/halls` - Verified partner AC/Mini marriage halls in Trichy (Ravi Mini Hall, Sushi Hall, Omanthur Mandapam).
   - `/about` - Chef V. Manivannan profile, culinary legacy, hygiene & purity standards.
   - `/contact` - Direct dialers, city booking office, head office location maps, and booking inquiry form.

2. **Strict 1-Page Quotation Generator**:
   - Generates an isolated, perfectly styled 1-page A4 letterhead quotation popup ready for printing or instant PDF export with 0 excess trailing pages.

3. **High SEO & Schema.org Structured Data**:
   - `LocalBusiness` / `CateringService` Schema.org JSON-LD structured data.
   - Dynamic meta titles, keywords, OpenGraph previews, and localized Tamil/English geo-targeting.

4. **Pure-Veg Cultural Aesthetics**:
   - Custom-tailored "Warm Peach Silk" (`#FFF9F5` / `#FEDCC8`), "Royal Crimson Maroon" (`#831726` / `#9B192A`), and "Temple Gold" (`#EDB023`) color palette with responsive typography and micro-animations.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS + Custom Design System
- **Icons**: Lucide React
- **Animations / Micro-Interactions**: Framer Motion & Canvas Confetti
- **Routing**: React Router DOM v7

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

### 4. Preview Production Build
```bash
npm run preview
```
